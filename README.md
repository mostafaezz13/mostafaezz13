Hey there! 👋 I'm **Mostafa Ezz**, a passionate **Full Stack Web Developer** focused on building **modern**, **responsive**, and **high-performance** web applications that deliver a smooth user experience. 🚀

My journey in tech started with a strong interest in **design and frontend development**, where I learned tools like **Figma** and **Photoshop** to create visually appealing interfaces. Over time, I expanded into **full-stack development**, combining design with powerful backend logic.

I have solid experience working with **HTML, CSS, JavaScript, Bootstrap, and React**, and I'm currently diving deeper into **backend development** using **Node.js** and **MySQL** to build complete, scalable applications.

I believe in learning by doing, so I focus on **building real-world projects** instead of just watching tutorials. This approach helped me improve my skills and create projects that I can proudly showcase in my portfolio.

Currently, I'm a student at **WE Applied Technology School (Programming Track)**, and I'm working on developing projects that solve real problems — especially ideas that help students, like platforms for managing expenses or preparing affordable meals.

I'm always exploring new technologies, improving my skills, and looking for opportunities to **collaborate on exciting projects** and grow as a developer.
